# Limitations

- Correlations are heuristic and may produce false positives.
- Shared IP addresses can be coincidental.
- Missing timestamps limit ordering claims.
- Hostname-only matching is weak.
- Collection coverage describes collected data, not all host activity.
- Hash verification does not prove pre-collection authenticity.
- No machine learning or behavioral scoring is used.
- Report generation is synchronous.
- No dedicated authentication layer is implemented.
