# User Guide

## Basic workflow

1. Create an investigation.
2. Upload Linux authentication and web access logs.
3. Review the unified timeline.
4. Inspect event details and source references.
5. Review coverage, parsing, timestamp, and integrity quality.
6. Run cross-system correlation.
7. Review and dismiss suggested correlations.
8. Generate PDF or CSV reports.

## Dashboard

Open `/` for the investigation dashboard. The evidence workspace remains at `/workspace`.

## Evidence handling

Uploaded files are hashed with SHA-256 and preserved. The original evidence is not modified by parsing or reporting.
